1. HIGH-LEVEL SYSTEM ARCHITECTURE
================================================================================
SENTINEL is a pnpm + Turborepo monorepo + Python FastAPI service structured into 4 workspaces:

  1. apps/web         (@sentinel/web)          — Next.js 16 App Router UI + Backend API routes + PostgreSQL/Drizzle DB + Better Auth
  2. services/engine  (sentinel-engine)        — Python 3.12 FastAPI statistical detection & personal baseline engine
  3. packages/shared  (@sentinel/shared)       — Shared Zod schemas, units/bounds, AES-256-GCM PHI crypto, SHA-256 audit hash helpers
  4. workers/inbox    (@sentinel/inbox-worker) — Cloudflare Email Routing worker for caregiver email replies (OK / CALL ME / SNOOZE)

End-to-End Execution Flow:
  [Browser UI (Next.js pages + React components)]
      |  fetch('/api/v1/...') / EventSource('/api/v1/stream') / Better Auth
      v
  [Next.js Backend Route Handlers (apps/web/src/app/api/**)]
      |-- Auth & Role checks: requireSession(), checkPatientScope(), resolveIngestAuth()
      |-- Database reads/writes: Drizzle ORM -> PostgreSQL (with RLS + append-only SHA-256 audit_logs)
      |-- Physiological scoring bridge (apps/web/src/lib/engine/client.ts):
      |       -> When ENGINE_URL is configured (or running non-Vercel local):
      |            POST ${ENGINE_URL}/v1/score/evaluate  (default: http://127.0.0.1:8000/v1/score/evaluate)
      |       -> Fallback / Vercel serverless built-in mode (when ENGINE_URL unset on Vercel):
      |            fallbackEvaluateLocal() in apps/web/src/lib/engine/client.ts
      |-- Clinician Ambient OPD Scribe (apps/web/src/lib/clinician/opd-scribe.ts + diarization.ts):
      |       -> Deterministic multilingual parser (code-mixed EN / Kannada / Hindi) + NLM RxNorm lookup
      |       -> Zero external LLM calls required; persisted cleanly in `opd_consultations`
      v
  [Alert Policy + Escalation + Outbox (apps/web/src/lib/alerts/policy.ts & outbox.ts)]
      |-> SSE live stream push (/api/v1/stream)
      |-> External alert channels: Web Push (VAPID), ntfy, Resend email, Telegram, SMS flag

4. PYTHON FASTAPI ENGINE (services/engine/**)
================================================================================
FastAPI App (`services/engine/app/main.py`):
  - GET  /healthz                        -> Service liveness check
  - GET  /readyz                         -> Contracts version & config readiness check
  - GET  /v1/sim/scenarios               -> Lists 11 deterministic physiological simulation scenarios
  - POST /v1/sim/generate                -> Generates synthetic scenario vitals (`sim/generator.py`)
  - POST /v1/baseline/fit                -> Fits personal circadian median + MAD baseline (`engine/baseline.py`)
  - POST /v1/score/evaluate              -> Full L1 + L2 + L3 + Partial NEWS2 evaluation (`engine/detectors.py`)
  - POST /v1/eval/benchmark              -> Runs ablation & lead-time benchmark (`engine/eval_harness.py`)
  - GET  /v1/datasets                    -> Lists PMData / LifeSnaps / WESAD / MMASH dataset loaders (`engine/datasets/loaders.py`)

Internal Python Modules:
  - engine/features.py                   -> UTC timestamp parsing, IST circadian block mapping, quarantine exclusion filtering, hourly rollups.
  - engine/baseline.py                   -> Exponentially weighted median + MAD dispersion with prior blending (warming_prior -> learning -> calibrated).

  - sim/generator.py                     -> Synthetic physiological trajectory generator (`early_infection`, COPD, exercise, silence, etc.).
