# Phase 5 Plan — Patient, Caregiver & Clinician Dashboards

## Objectives
1. **Shared Dashboard APIs & Data Layer:**
   - `GET /api/v1/dashboard/patient`: aggregates latest `risk_assessments`, active open `alerts`, baseline status (`warming_prior`/`learning`/`calibrated`), top driver contributions, latest `checkin_events`, active `medications`, ambient weather context, and `SYNTHETIC` origin indicator (supporting optional `?patientId=` for caregiver/clinician views guarded by `checkPatientScope`).
   - `POST /api/v1/checkins`: persists structured quick check-ins (`"I feel okay"`, `"Feeling tired / unwell"`, optional symptoms + note) to `checkin_events` and emits SSE update.
   - `GET /api/v1/vitals/series`: queries real hourly rollups (`vital_rollups_hourly`) & raw samples (`vital_samples`), plus personal baseline band (`median ± 1.6*sigma`), `detector_decision_logs` change-points, `alerts`, and `medication_events` overlays for `/clinician` and `/signals` zoomable charts (`24h`, `7d`, `30d`).
   - `GET /api/v1/clinician/cohort`: returns all consented patients accessible to the authenticated clinician/caregiver with latest Deterioration Index, level, valid baseline days, wear ratio, open alert count, and synthetic state.
   - `GET/PATCH /api/v1/settings/profile`: reads/updates patient quiet hours, daily budget, country/emergency numbers, locale (`en`/`kn`/`hi`), and condition modules.
   - `GET /api/v1/privacy/export` & `POST /api/v1/privacy/erase`: DPDP Act 2023 full JSON data export and soft-delete / anonymization erasure path (`deleted_at` + audit log).

2. **UI Pages & Accessible Clinical Components (`DESIGN.md` + Lucide + Apache ECharts):**
   - Shared top nav bar (`SentinelNav`) highlighting role views (`/today`, `/caregiver`, `/clinician`, `/signals`, `/alerts`, `/ingest`, `/settings`) plus persistent `SYNTHETIC` badge whenever synthetic telemetry is active.
   - **`apps/web/src/components/charts/vitals-chart.tsx`**: Apache ECharts (`canvas` renderer) time-series chart with baseline shaded tolerance band (`normalLow..normalHigh`), alert markPoints, change-point markLines, DataZoom pan/zoom slider, loading skeleton (`h-[340px]`), empty state, learning badge, and keyboard-accessible tabular data companion (`<details>` / responsive table).
   - **`/today` (`apps/web/src/app/today/page.tsx`)**: Elder Mode! `>=18px` base typography, `>=48px` tall touch buttons, `>=8px` spacing, calm color + icon + text semantic card (Stable / Watch / Warning / Urgent), plain-language summary (`What changed · Since when · What to do next`), "Why?" explainability drawer, Read Aloud speech synthesis (`window.speechSynthesis`), one-tap `I Feel Okay` / `Not Feeling Well` check-in (`checkin_events`), and unmistakable `Call Caregiver` / `Emergency 112` button.
   - **`/caregiver` (`apps/web/src/app/caregiver/page.tsx`)**: Multi-patient Care Circle overview with live `EventSource('/api/v1/stream')`, active alert acknowledge/snooze/escalate controls, latest elder check-in & medication status, and outbox delivery status.
   - **`/clinician` (`apps/web/src/app/clinician/page.tsx`)**: Cohort triage panel, zoomable Apache ECharts vitals + Deterioration Index trend (`24h`/`7d`/`30d` + window-vs-window comparison), Partial NEWS2 7-row transparent table, detector decision log, and medication/alert overlays.
   - **`/signals` (`apps/web/src/app/signals/page.tsx`)**: Raw Signal Explorer allowing inspection of individual metrics (`resting_heart_rate`, `hrv_rmssd`, `spo2`, `respiratory_rate`, `skin_temp_deviation`, `steps`, `sleep_efficiency`), quality flags (`motion_artifact`, `unit_converted`), and exclusion quarantine window creator (`/api/v1/exclusions`).
   - **`/settings` (`apps/web/src/app/settings/page.tsx`)**: Unified hub linking Consent Ledger (`/settings/consent`), Device API Keys (`/ingest`), Quiet Hours / Daily Budget / Emergency Numbers / Condition Modules editor, Locale selector (`en`/`kn`/`hi`), and DPDP JSON Export / Erasure controls.
