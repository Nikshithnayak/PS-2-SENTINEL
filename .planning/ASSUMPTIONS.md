# Project Assumptions — SENTINEL

> Logged during Phase 0 (`ASSUMPTIONS.md`). Every assumption below is explicitly surfaced, bounded, and paired with its fallback if false.

| ID | Assumption | Impact if Wrong | Mitigation / Fallback |
|---|---|---|---|
| `ASM-001` | Local Windows dev host does not have Docker Desktop or native `psql` installed (`docker` & `psql` missing in Phase 0 probe). | Cannot run `docker compose up` locally inside this agent environment without a fallback Postgres runtime. | Write full, verified `docker-compose.yml` for standard containerized environments AND integrate `embedded-postgres` (real local PostgreSQL TCP server) for local Windows testing, Drizzle migrations, RLS verification, and Playwright E2E runs. |
| `ASM-002` | Most target wearable users do not have active enterprise partner credentials for Garmin Health API, Whoop, or Google Health API during evaluation. | Live OAuth pulls from commercial wearable clouds return 401/unauthorized without partner keys. | Build full real `ProviderAdapter` interfaces + mockable/env-gated adapters documented in `.env.example` and `docs/SETUP-NEEDED.md`, AND make streaming Apple Health `export.xml`, Google/Fitbit Takeout archives, CSV upload with column mapper, authenticated REST Ingestion API, and seeded Synthetic Mode 100% functional locally with zero external keys. |
| `ASM-003` | Standard smartwatch/fitness-band users wear devices ≥12 hours/day including overnight sleep most days. | Sparse nighttime wear weakens nocturnal RHR, HRV, RR, and skin temperature baseline estimates. | Implement explicit wear-time estimation, minimum-sample calibration rules (`Learning, day X of 14`), shrinkage from age/sex/condition priors, and a distinct `Device silent for N hours` safety alert. |
| `ASM-004` | Elderly patients in Mangaluru/Karnataka commonly have Fitzpatrick skin types IV–VI and may experience cold extremities or arthritic tremors. | Wrist PPG SpO₂ and optical HRV suffer elevated noise and occult hypoxemia underestimation. | Gate baseline updates and L2/L3 inference on low-motion resting windows, penalize low-confidence SpO₂ samples, and never rely on single-point SpO₂ readings without persistence or multi-signal corroboration. |
| `ASM-005` | Caregivers/clinicians may lack paid Twilio SMS/WhatsApp accounts or Cloudflare custom domain Email Routing during local demo. | Outbound SMS/WhatsApp or live MX inbound email replies fail without vendor secrets. | Provide free-tier active channels (**In-App SSE**, **VAPID Web Push**, **ntfy**, **Telegram Bot**, **SMTP/Resend Email** with local Ethereal/outbox inspector fallback) + **Cloudflare Worker inbound webhook simulator** so full round-trip ack flows execute end-to-end cleanly. |
| `ASM-006` | India emergency defaults (`112` unified emergency, `108` ambulance) are the baseline deployment target for Nitte Pharma Innovation Centre (Mangaluru). | Deployment in another state or country requires different emergency dispatch numbers. | Store emergency numbers per organization/country profile in settings (defaulting to India `112` / `108`) so every urgent screen renders configurable verified numbers. |
| `ASM-007` | Public physiological datasets (`LifeSnaps`, `PMData`, `WESAD`, `MMASH`) require external download/DUA acceptance if fetched full-size (hundreds of MB to GB). | Offline evaluation suite cannot bundle gigabytes of raw third-party archives directly in git. | Build dataset adapter loaders in `services/engine/datasets/` with schema validation + license checks, small schema-faithful sample fixtures for CI fast runs, and documented fetch scripts for full external benchmark runs. |
| `ASM-008` | Optional LLM phrasing (`OPENAI_API_KEY` or local Ollama) is absent in restricted offline/CI runs. | Alert explanations cannot rely on a remote LLM call. | Build deterministic structured template explainer (`en` / `kn` / `hi`) as the primary guaranteed explanation renderer, with an optional PII-stripped LLM phrasing enhancer behind a feature flag. |
