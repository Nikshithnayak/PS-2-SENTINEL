# Risk Register — SENTINEL

| ID | Category | Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|---|---|
| `RISK-01` | Infrastructure | Local Windows environment lacks Docker Desktop & `psql`, risking broken DB tests before deploy | **High (Observed)** | High | Keep full `docker-compose.yml` for containerized hosts AND run `embedded-postgres` automatically in dev/CI when no external `DATABASE_URL` is active so real Postgres SQL/RLS runs everywhere. |
| `RISK-02` | Wearable Ecosystem | Legacy Fitbit Web API shut down (Nov 2, 2026); Google Health / Garmin / Whoop require partner OAuth | **Confirmed** | Medium | Abstract all sources behind `ProviderAdapter`; ship working Apple Health XML streaming, Takeout/CSV upload, Open API push, and Synthetic Mode out-of-the-box alongside optional Open Wearables / Google Health adapters. |
| `RISK-03` | Clinical Equity | Dark skin tones (Fitzpatrick IV–VI) & geriatric cold extremities cause wrist PPG SpO₂ & HRV inaccuracy | **High** | High | Gate baseline learning and alerts on low-motion windows (`steps == 0`), propagate explicit `data_confidence`, never fire uncorroborated single-point SpO₂ emergencies, and surface equity caveats in Model Card. |
| `RISK-04` | Alert Fatigue | Repeated exercise/charging/transient artifacts flood caregivers -> silenced notifications | **High** | Critical | `N of M` persistence, hysteresis, cooldowns, daily non-urgent alert budget, motion-confounder suppression, and separate non-clinical `device_silent` signal. |
| `RISK-05` | Clinical Safety | Users or judges perceive screening alerts as medical diagnosis | **Medium** | Critical | Strict copy policy ("changes from your personal normal"), mandatory screening disclaimer, no automated clinical orders, prominent `112`/`108` emergency action on Urgent screens. |
| `RISK-06` | Licensing | `paper-design/liquid-logo` uses PolyForm Shield 1.0.0; `Open-LLM-VTuber` includes proprietary Live2D terms | **Medium** | Medium | Never copy `liquid-logo` or bundle Live2D; install only OSI-licensed packages (`@paper-design/shaders-react` Apache-2.0, `motion` MIT, `@shadergradient/react` MIT, `@react-three/fiber` MIT). |
| `RISK-07` | Performance / Low-End Android | Heavy WebGL shaders (`ShaderGradient` / R3F) degrade LCP > 2.5s or crash weak mobile GPUs | **Medium** | High | Client-only dynamic import (`ssr: false`), max 1 WebGL context per page, `IntersectionObserver` pause off-screen, static CSS gradient fallback for `prefers-reduced-motion` / low-tier WebGL. |
| `RISK-08` | Privacy / DPDP 2023 | Accidental PII leakage in outbound context APIs (Open-Meteo, Nominatim), logs, or optional LLM calls | **Medium** | Critical | Strict outbound sanitizer (strip IDs/names, snap weather coordinates to city centroid), field-level AES-256-GCM encryption for identifiers, PII-redacted structured logging, and hash-chained audit logs. |
